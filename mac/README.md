# Salesforce CLI Onboarding（Codex 版 / macOS）

このフォルダは `sf`（Salesforce CLI）の導入確認と質問回答専用のエージェントです。
OpenAI Codex で使うことを前提にしています。

> **うまくいかないときは**
> 画面に出ている文字をそのままコピーして、DigiMan の担当者までお送りください。
> ご自身で権限やセキュリティの設定を変える必要はありません。

## 必要なもの

- **macOS**（この手順は macOS 向けです。Windows の方は Windows 版のフォルダをお使いください）
- **Codex CLI**（入れ方は手順 2）
- **ChatGPT アカウント**（Plus 以上のプランで、CLI の利用が案内されています）
- **Node.js**（`npm` コマンドが使えること）
  Salesforce CLI の導入に使います。入っていない場合は、先に社内手順で入れてください。

---

## 1. 準備する

### 1-1. zip を解凍する

受け取った zip をダブルクリックして解凍します。
置き場所はどこでも構いませんが、迷ったら「書類」フォルダに置いてください。

**フォルダごと移動してください。** 中身のファイルだけを選んでコピーすると、
`.codex` と `.agents` という「.」で始まるフォルダが抜け落ちます。
これらは macOS の Finder では既定で見えません（`Cmd + Shift + .` で表示を切り替えられます）。

### 1-2. ターミナルを開く

Launchpad →「その他」→「ターミナル」を開きます。
以降のコマンドは、この黒い（または白い）画面に貼り付けて Enter を押します。

### 1-3. フォルダの中に移動する

ターミナルに `cd ` と打ち、最後に**半角スペースを 1 つ**入れます。
そのまま、解凍したフォルダを Finder からターミナルの画面へ**ドラッグ＆ドロップ**して、Enter を押します。

こうするとフォルダ名を打たずに移動できます。解凍後のフォルダ名が
`digiman-sf-onboarding-codex` のように末尾が違っていても、この方法なら問題ありません。

### 1-4. 中身が揃っているか確認する

移動できたら、次を貼り付けて Enter。

```
ls -a && ls .codex .agents/skills
```

`AGENTS.md` `README.md` `.codex` `.agents` と、`config.toml` `salesforce-cli-install` が
表示されれば正常です。`.codex` や `.agents` が無い場合は解凍からやり直してください。

---

## 2. Codex を入れる

すでに入っている場合はこの手順を飛ばして、手順 3 に進んでください。

**複数の方法を混ぜないでください。** 混ぜると、どちらが動くかが環境によって変わってしまいます。

```
curl -fsSL https://chatgpt.com/codex/install.sh | sh
```

npm を使い慣れている場合は `npm install -g @openai/codex`、
Homebrew の場合は `brew install --cask codex` でも構いません。どれか 1 つだけにしてください。

### 入ったか確認する

```
command -v codex
```

パスが 1 行表示されれば成功です。

**何も表示されない、または `command not found: codex` と出た場合**、
インストール時の最後のメッセージに `export PATH=...` で始まる 1 行が出ています。
その 1 行をターミナルに貼り付けて Enter を押し、**ターミナルを一度閉じて開き直してから**、
手順 1-3 のフォルダ移動をやり直してください。

（これは、インストール先の場所を macOS がまだ知らない、という状態です）

---

## 3. このフォルダで Codex を起動する

**必ずこのフォルダの中で起動してください。**
フォルダの外から起動すると、このフォルダの指示は一切読み込まれません。
しかもエラーは出ず、ただの汎用エージェントとして普通に応答するため、失敗に気づけません。

手順 1-3 でフォルダの中にいる状態のまま、次を実行します。

```
codex
```

フォルダを移動せずに起動したい場合は、`codex -C ` と打って半角スペースを入れ、
フォルダを Finder からドラッグ＆ドロップして Enter でも構いません。

`codex フォルダ名` のようにパスをそのまま書くと、フォルダ指定ではなく
「エージェントへの指示文」として解釈されるので注意してください。

---

## 4. 初回の確認に答える

初回起動時は、数ステップの初期設定があります。その中で次の 2 つが行われます。

- **サインイン**: `Sign in with ChatGPT` を選ぶとブラウザが開きます
- **フォルダの信頼確認**: `Do you trust the contents of this directory?` と表示されたら
  `Yes, continue` を選びます

信頼確認の選択肢は `Yes, continue` と `No, quit` の 2 つだけで、
信頼しない場合は Codex がそのまま終了します。
また、信頼しないと `.codex/config.toml`（このフォルダの推奨設定）が読み込まれません。

---

## 5. 最初の一文を送る

Codex は起動しただけでは何も話しません。入力欄に次を送ってください。

```text
Salesforce CLI が使えるか確認して
```

これを送ると、エージェントが自己紹介をして、`sf` が導入済みかどうかを確認し、
次に何を依頼すればよいかを 1 つ教えてくれます。

そのあとは、次のような文をそのまま送れます。

- 導入を進めたいとき
```text
Salesforce CLI をインストールして
```
- 良い使い方を相談したいとき
```text
Salesforce CLI で業務効率化する使い方を教えて
```
- 詳しく相談したいとき
```text
salesforce cliを使えるエージェントをつかってどうすれば業務効率化できると思うか？良い使い方を教えて
```

## 6. インストール時に確認が出ます

Codex は既定で、次の 2 つにあなたの承認を求めます。

- このフォルダの外への書き込み
- ネットワークを使うコマンドの実行

Salesforce CLI のインストールはこの両方に当たるため、途中で許可を求める表示が出ます。
**これは正常な動作です。** 内容を確認して許可してください。

環境によっては、一度エラーになってから許可を求める表示が出ることがあります。
その場合も、許可すればそのまま続きます。

### 何度も聞かれるのが煩わしい場合

このフォルダの `.codex/config.toml` の末尾に、ネットワークだけを許可する設定を
コメントとして用意してあります。行頭の `#` を消して保存し、Codex を起動し直してください。
**このフォルダのエージェントだけ**が対象です。

`/permissions` というコマンドでも権限を変えられますが、
**どれを選ぶかは DigiMan 担当に確認してください。一番強い設定は選ばないでください。**
サンドボックス（安全装置）を丸ごと外してしまう選択肢が含まれています。

## 7. フォルダの構成

```
digiman-sf-onboarding-codex/
├─ AGENTS.md                  このフォルダの正の指示（Codex はこれを読む）
├─ README.md                  このファイル
├─ .codex/
│  └─ config.toml             このフォルダでの推奨設定
└─ .agents/skills/
   └─ salesforce-cli-install/
      └─ SKILL.md             インストールを依頼されたときの手順
```

`AGENTS.md` が正の指示です。振る舞いを変えたいときはここを編集してください。
エージェント自身に「いまの指示を AGENTS.md に追記して」と頼むこともできます。

> **編集した内容は、いま動いているセッションには反映されません。**
> `AGENTS.md` と `.codex/config.toml` は、どちらも Codex の起動時に一度だけ読み込まれます。
> 編集したら Codex を一度終了して、起動し直してください。

## Windows で使いたい場合

**Windows 版のフォルダを別に用意しています。そちらをお使いください。**

このフォルダの指示は macOS のシェルを前提に書かれているため、
PowerShell では導入確認のコマンドが動きません。

Windows 版は PowerShell 前提で書き直してあり、WSL2 は不要です。
セットアップガイドの「すぐに使えるフォルダ」で **Windows** を選ぶとダウンロードできます。

## 補足: Codex が読む指示ファイルについて

このフォルダの指示は `AGENTS.md` に書かれています。
`CLAUDE.md` は Codex の公式ドキュメントに記載がなく、既定では読み込まれません
（読ませたい場合は `project_doc_fallback_filenames` に自分で追加する必要があります）。

なお Codex は `~/.codex/AGENTS.md`（全プロジェクト共通の個人設定）も読み込み、
このフォルダの `AGENTS.md` と連結します。
挙動がおかしいときは、そちらに矛盾する指示が入っていないかも確認してください。

同じフォルダを Claude Code でも使いたい場合は、Claude Code 版を別途 DigiMan にご相談ください。

Windows でお使いの場合は、Windows 版のフォルダを別途ご用意しています。
